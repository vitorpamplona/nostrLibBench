## Notes on the ranked rows

- **JVM (Kotlin/Java) `quartz-parallelverifier`** (NostrClient.fetch + Quartz's ParallelEventVerifier accessory (batched Event.verify() on Dispatchers.Default)): As quartz-fetch, but the callback submits each event to ParallelEventVerifier (default batch 256, parallelism 8), which fans Event.verify() out over Dispatchers.Default and delivers in order. Quartz's documented speed option (an opt-in accessory), so it is a ranked entry of its own, like other libraries' speed options; it verifies on several cores, which the CPU columns show.
